# ROOM / ROOM

локальный редактор коротких игровых маршрутов.

соберите мир из 3–7 комнат, добавьте текст, изображения и двери между ними. затем проверьте прохождение и скачайте автономный ZIP с `index.html`, `styles.css`, `play.js`, `project.json` и локальными изображениями.

## как открыть

самый простой вариант — открыть `index.html` в браузере. если браузер ограничивает локальные файлы, запустите небольшой сервер из корня проекта:

```bash
python3 -m http.server 4173
```

после этого откройте [http://localhost:4173](http://localhost:4173).

## как пользоваться

1. выберите шаблон: ночной маршрут, музейный тур или квест из заметок;
2. измените название и текст комнат;
3. добавьте локальные изображения в формате JPG, PNG или WebP до 8 мб;
4. соедините комнаты дверями и при необходимости добавьте условия;
5. нажмите `играть`, чтобы пройти маршрут с текущей комнаты;
6. нажмите `скачать ZIP`, когда статус маршрута не показывает ошибок.

изменения и прогресс остаются в `localStorage` текущего браузера. кнопки `сохранить JSON` и `открыть JSON` помогают перенести проект вручную. данные не отправляются на сервер.

## GitHub Pages

репозиторий уже содержит workflow для GitHub Pages. после первого push в ветку `main` откройте в настройках репозитория раздел **Pages** и выберите источник **GitHub Actions**. workflow опубликует корень репозитория как статический сайт.

если нужен отдельный маршрут, скачайте ZIP и загрузите его содержимое в другой репозиторий или в папку, которую обслуживает GitHub Pages.

## ограничения

это браузерный редактор без аккаунтов, backend, аналитики, мультиплеера и внешних AI‑моделей. изображения и черновики хранятся только на устройстве автора. экспортированный маршрут работает без сервера и не содержит пользовательского JavaScript.
