# Site as Game — дизайн MVP

## направление

одностраничный статический редактор «стол с картой»: слева — нумерованный список комнат, в центре — карта связей на SVG, справа — свойства выбранной комнаты. в режиме Preview/Play этот же проект становится короткой экскурсией: сцена, понятные действия переходов, возврат к карте и сброс прогресса.

визуальный голос — авторская бумажная карта и афиша: плоские бумажные фоны, рамки, координаты, стрелки, печатные номера и простые символы. три шаблона получают отдельные ограниченные палитры и пары шрифтов с кириллическими fallback.

## данные и поведение

проект хранится в браузере как JSON: метаданные, 3–7 комнат, флаги и переходы. комната имеет id, номер, заголовок, текст, локальное изображение с alt-текстом, координаты на карте и до трёх переходов. переход может требовать один флаг и устанавливать один флаг. Runtime хранит currentRoomId, visited и flags в localStorage.

пустые значения и битые цели подсвечиваются в редакторе. нельзя удалить последнюю комнату; стартовая комната всегда одна. на карте есть текстовый список как доступный fallback. клавиатурные кнопки, фокус, touch-зоны и prefers-reduced-motion поддерживаются в базовых стилях.

экспорт — полностью локальный ZIP с index.html, styles.css, play.js, project.json и папкой assets. в экспортируемом runtime нет пользовательского кода и внешнего backend.

## успешный сценарий

1. автор выбирает шаблон, меняет название, редактирует комнату и добавляет локальное изображение.
2. автор выбирает другую комнату в rail, настраивает переход и при необходимости флаг.
3. Preview показывает проход по текущему проекту; Play сохраняет прогресс.
4. «вернуться к карте» возвращает в Index, «начать заново» очищает сохранение.
5. «скачать ZIP» отдаёт автономный архив для GitHub Pages.

## ограничения

только vanilla HTML/CSS/JS и browser APIs. без аккаунтов, аналитики, API-ключей, серверной базы, внешней AI-модели и пользовательского JavaScript.
